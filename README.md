# ⏰ Date Time Project (Real-Time Clock)

This is a simple and responsive web application that displays the **current time and date in real-time** using JavaScript.

## 🚀 Features

* 🕒 Live updating clock (updates every second)
* 📅 Displays full date (day, month, year)
* 🎨 Styled using Bootstrap
* 📱 Responsive design (works on all devices)

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## 📂 Project Structure

```
Data_Time_Project/
│── index.html
│── styles.css
```

## ⚙️ How It Works

* JavaScript `Date()` object is used to get current time and date.
* `setInterval()` updates the time every second.
* The time is displayed dynamically using DOM manipulation.
